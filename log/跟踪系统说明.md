# 🎯 跟踪系统功能说明

## ✅ 完成的功能

### 1. **自动跟踪选择** ✅
- 进入TRACK模式时自动选择第一个安全区人物
- 只跟踪已授权的人物（绿框显示的A、B、C）
- 自动排除报警区人物和未授权人物

### 2. **手动切换目标** ✅
- **PREV按钮**: 选择上一个安全区人物
- **NEXT按钮**: 选择下一个安全区人物
- 循环切换所有可跟踪目标

### 3. **坐标输出功能** ✅
- 实时输出跟踪目标的**脸部识别框中心点坐标**
- 同时输出完整的边界框信息
- 使用print输出到控制台

### 4. **视觉标识系统** ✅
- 🔵 **蓝色框**: 当前跟踪目标（最粗线条）
- 🎯 **十字标记**: 在跟踪目标中心点绘制蓝色十字
- 🎯 **特殊标签**: "🎯A: 0.85" 标识跟踪目标

## 🎮 操作流程

### 自动跟踪
```
1. 切换到 TRACK 模式
2. 系统自动选择第一个安全区人物开始跟踪
3. 实时输出坐标信息
```

### 手动切换
```
1. 在 TRACK 模式下
2. 按 PREV/NEXT 按钮切换跟踪目标
3. 每次切换都会输出新目标的坐标
```
