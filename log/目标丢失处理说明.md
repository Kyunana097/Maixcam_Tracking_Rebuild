# 🎯 目标丢失处理功能说明

## ✅ 完成的功能

### 1. **丢失目标坐标保持** ✅
- 目标丢失时继续输出上次记录的坐标
- 坐标输出标记为 `[LOST]` 状态
- 保持坐标连续性，避免跟踪中断

### 2. **1秒超时机制** ✅
- 连续30帧（约1秒@30fps）未检测到目标才停止跟踪
- 超时前持续输出上次坐标
- 超时后自动停止跟踪

### 3. **不切换人物策略** ✅
- 目标丢失时不自动切换到其他人物
- 专一跟踪指定目标
- 只有手动切换（PREV/NEXT）才改变目标

### 4. **视觉状态反馈** ✅
- 界面显示目标丢失时间
- 不同颜色标识跟踪状态
- 实时显示丢失倒计时

## 📊 工作流程

### 正常跟踪
```
1. 检测到目标 → 输出实时坐标
2. 更新上次坐标记录
3. 重置丢失帧计数器
```

### 目标丢失处理
```
1. 未检测到目标 → 丢失帧数 +1
2. 输出上次记录的坐标 + [LOST]标记
3. 检查是否超过30帧限制
4. 超时 → 停止跟踪
```

### 目标重新出现
```
1. 检测到同名目标 → 重置丢失帧数
2. 更新坐标记录
3. 恢复正常跟踪状态
```

## 🔧 技术实现

### 核心参数
```python
self.max_lost_frames = 30          # 最大丢失帧数（1秒@30fps）
self.target_lost_frames = 0        # 当前丢失帧数
self.current_target_name = None    # 当前跟踪目标名称
self.last_tracked_coordinates = None # 上次坐标 (center_x, center_y, bbox)
```

### 丢失检测逻辑
```python
def _auto_track_output(self):
    # 寻找当前目标
    current_target = None
    for person in self.safe_zone_persons:
        if person['name'] == self.current_target_name:
            current_target = person
            break
    
    if current_target:
        # 找到目标 → 正常跟踪
        self.target_lost_frames = 0
        self._output_current_coordinates(current_target)
    else:
        # 目标丢失 → 输出上次坐标
        self.target_lost_frames += 1
        if self.target_lost_frames <= self.max_lost_frames:
            self._output_last_coordinates()  # 输出[LOST]坐标
        else:
            self._stop_tracking()  # 停止跟踪
```

### 坐标保持机制
```python
def _update_last_coordinates(self, person_data):
    """更新并保存坐标"""
    x, y, w, h = person_data['bbox']
    center_x = x + w // 2
    center_y = y + h // 2
    self.last_tracked_coordinates = (center_x, center_y, (x, y, w, h))

def _output_last_coordinates(self):
    """输出保存的坐标"""
    if self.last_tracked_coordinates:
        center_x, center_y, bbox = self.last_tracked_coordinates
        print(f"📍 跟踪坐标 [{self.current_target_name}]: 中心点({center_x}, {center_y}) | 边界框{bbox} [LOST]")
```

    └─────────────────────────────────┘
