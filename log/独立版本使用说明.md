# 独立版本使用说明

## 概述

为了解决MAIXVISION只支持单独运行一个文件的问题，我们创建了独立版本的文件，所有UART通信代码都直接集成在主程序中。

## 文件说明

### 1. 测试文件
- **`test_uart_simple.py`**: 简单UART连接测试
- **`test_uart_standalone.py`**: 完整UART功能测试

### 2. 主程序文件
- **`main_standalone.py`**: 独立版本主程序，包含完整的UART通信功能

## 使用方法

### 步骤1：测试UART连接

#### 简单测试（推荐）
```bash
# 在MAIXVISION中运行
python test_uart_simple.py
```

#### 完整测试
```bash
# 在MAIXVISION中运行
python test_uart_standalone.py
```

### 步骤2：观察LED状态
- **🟢 绿色LED常亮**: 连接成功
- **🔴 红色LED闪烁**: 连接失败
- **🔵 蓝色LED**: 报警状态指示

### 步骤3：运行主程序
```bash
# 在MAIXVISION中运行
python main_standalone.py
```

## 功能特性

### 1. 独立UART通信
- 不依赖外部模块
- 集成握手验证机制
- 支持坐标和报警状态发送

### 2. 云台控制
- 启动/停止云台跟踪
- 实时坐标传输
- 报警状态控制

### 3. 用户界面
- 虚拟按钮控制
- 状态显示
- LED反馈

## 硬件连接

```
MaixCam UART ←→ MSPM0G3507 UART
- TX → RX
- RX → TX  
- GND → GND
```

## 软件配置

- **UART端口**: `/dev/ttyS1`
- **波特率**: 115200
- **数据位**: 8
- **停止位**: 1
- **校验位**: 无

### 1. 连接测试

3. 确认连接成功

### 2. 功能测试

1. 运行 `main_standalone.py`

## 故障排除

### 1. 连接失败
**症状**: 红色LED闪烁
**解决方案**:
- 检查硬件连接
- 确认UART端口配置
- 检查波特率设置

### 2. 握手失败
**症状**: 连接建立但握手失败
**解决方案**:
- 检查通信协议
- 确认数据格式
- 检查超时设置

### 3. 数据传输失败
**症状**: 握手成功但数据传输失败
**解决方案**:
- 检查数据帧格式
- 确认命令字节
- 检查数据长度
