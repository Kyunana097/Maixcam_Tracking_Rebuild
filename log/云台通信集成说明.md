# MaixCam云台追踪系统 - UART通信集成说明

## 概述

本文档说明如何在MaixCam和MSPM0G3507单片机之间建立UART通信连接，实现云台追踪功能。

## 系统架构

```
MaixCam (视觉识别) ←→ UART ←→ MSPM0G3507 (云台控制)
```

## 通信协议

### 数据帧格式
```
帧头: 0xAA 0xAA
X坐标: 高字节 低字节 (16位)
Y坐标: 高字节 低字节 (16位)  
校验位: (X高+X低+Y高+Y低) & 0xFF
帧尾: 0xFF 0xFF
```

**总长度：9字节**

### 坐标范围
- X坐标：0-65535
- Y坐标：0-65535
- 对应摄像头分辨率内的像素坐标

## 新增功能

### 1. UART通信模块
- **文件位置**: `src/hardware/uart_communication.py`
- **主要类**:
  - `UARTCommunication`: 底层UART通信
  - `GimbalController`: 云台控制器

### 2. 主程序集成
- **新增按钮**: GIMBAL按钮（云台控制开关）
- **新增功能**: 自动发送跟踪坐标到云台
- **状态显示**: 云台连接状态和跟踪状态

## 使用方法

### 1. 硬件连接
```
MaixCam UART ←→ MSPM0G3507 UART
- TX → RX
- RX → TX  
- GND → GND
```

### 2. 软件配置
- **UART端口**: 默认`/dev/ttyS1`
- **波特率**: 115200
- **数据位**: 8
- **停止位**: 1
- **校验位**: 无

### 3. 操作流程

#### 启动云台跟踪
1. 运行主程序：`python main.py`
2. 点击 **GIMBAL** 按钮启动云台跟踪
3. 切换到 **track** 模式
4. 系统会自动发送跟踪目标坐标到云台

#### 停止云台跟踪
1. 再次点击 **GIMBAL** 按钮停止跟踪
2. 或直接退出程序

## 界面说明

### 新增按钮
- **GIMBAL**: 云台控制开关
  - 蓝色：未激活
  - 绿色：已激活

### 状态显示
- **GIMBAL: ACTIVE**: 云台跟踪已激活
- **GIMBAL: INACTIVE**: 云台跟踪未激活

### 调试信息
按 **DEBUG** 按钮可查看：
- 云台系统状态
- UART连接状态
- 最后发送的坐标

## 代码结构

### UART通信模块
```python
# 创建云台控制器
gimbal_controller = GimbalController()

# 启动跟踪
gimbal_controller.start_tracking()

# 发送坐标
gimbal_controller.update_target(center_x, center_y, bbox)

# 停止跟踪
gimbal_controller.stop_tracking()
```

### 主程序集成
```python
# 初始化云台控制器
self.gimbal_controller = GimbalController()

# 在跟踪输出中发送坐标
if gimbal_status['tracking_active']:
    self.gimbal_controller.update_target(center_x, center_y, bbox)
```

## 故障排除

### 1. UART连接失败
- 检查硬件连接
- 确认串口设备路径（默认`/dev/ttyS1`）
- 检查波特率设置（115200）

### 2. 坐标发送失败
- 检查UART连接状态
- 确认单片机端接收程序运行正常
- 查看调试信息中的错误提示

### 3. 云台不响应
- 检查单片机端UART接收代码
- 确认数据帧格式正确
- 检查校验位计算

## 扩展功能

### 1. 自定义UART参数
```python
# 修改UART端口和波特率
gimbal_controller = GimbalController(
    uart_port="/dev/ttyS2", 
    uart_baudrate=9600
)
```

### 2. 添加更多控制命令
可以在`uart_communication.py`中扩展更多控制命令，如：
- 云台复位
- 速度控制
- 模式切换

## 注意事项

1. **坐标范围**: 确保发送的坐标在有效范围内（0-65535）
2. **发送频率**: 避免过于频繁的坐标发送，建议30fps以下
3. **错误处理**: 系统会自动处理UART连接错误
4. **资源清理**: 程序退出时会自动停止云台跟踪

## 测试建议

1. **连接测试**: 使用GIMBAL按钮测试UART连接
2. **坐标测试**: 在track模式下观察坐标发送
3. **调试模式**: 使用DEBUG按钮查看详细状态
4. **硬件验证**: 确认单片机端能正确接收和处理数据

## 技术支持

如遇到问题，请检查：
1. 硬件连接是否正确
2. 软件配置是否匹配
3. 调试信息中的错误提示
4. 单片机端接收程序是否正常运行
