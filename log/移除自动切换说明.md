## ✅ 现在的行为

### 🎮 **完全手动控制**
- **进入TRACK模式**: 不会自动开始跟踪任何目标
- **目标消失**: 不会自动切换到其他人物
- **启动跟踪**: 只能通过PREV/NEXT按钮手动激活

### 📍 **跟踪流程**
```
1. 进入TRACK模式
2. 界面显示: "Available: X persons" (青色)
3. 按PREV或NEXT按钮选择目标
4. 开始跟踪选定目标
5. 目标丢失时继续输出上次坐标
6. 超时1秒后停止跟踪
7. 需要手动重新选择目标
```

### 🎯 **跟踪状态**
- **未激活**: `Available: 2 persons` (需要手动选择)
- **正常跟踪**: `Tracking: A` (蓝色)
- **目标丢失**: `Tracking: A [LOST 0.5s]` (橙色)
- **停止跟踪**: 回到未激活状态

## 📊 用户体验变化

### 之前（有自动切换）
```
进入TRACK模式 → 自动跟踪第一个人 → 目标消失时切换到其他人
问题: 不受控制的自动行为
```

### 现在（纯手动控制）
```
进入TRACK模式 → 显示可用目标数 → 手动选择目标 → 专一跟踪该目标
优点: 完全可控，不会误切换
```

## 🎯 操作示例

### 启动跟踪
```
1. 切换到TRACK模式
2. 界面显示: "Available: 3 persons"
3. 按NEXT按钮: "➡️ 切换跟踪目标: A (1/3)"
4. 开始跟踪: "📍 跟踪坐标 [A]: 中心点(256, 160)"

### 目标丢失处理
```
1. 目标A消失
2. 界面显示: "Tracking: A [LOST 0.3s]"
3. 输出: "📍 跟踪坐标 [A]: 中心点(256, 160) [LOST]"
4. 超时后: "❌ 目标 [A] 丢失超过1秒，停止跟踪"

### 切换目标
```

2. 按NEXT: "➡️ 切换跟踪目标: B (2/3)"

```
