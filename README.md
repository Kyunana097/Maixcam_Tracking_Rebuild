# MaixPy视觉识别云台系统

## 项目简介

基于MaixPy和M0G3507主控的智能视觉识别云台系统，能够识别和跟踪特定人物目标，并提供安全监控功能。

## 系统功能

### 1. 人物识别功能

- 识别三个不同人物（动漫或真人形象，上半身，不大于5x5cm²）
- 人物贴在白底A4纸上，摄像头距离不少于50厘米
- 使用绿色框标记识别到的人物

### 2. 目标学习与跟踪

- 将目标人物贴纸放置在摄像头前进行学习和记录
- 贴纸移开后，自动识别A4纸上的对应人物
- 使用红色框标记目标人物

### 3. 安全监控系统

- 检测A4纸上是否存在目标人物
- 无目标人物时输出"SAFE"
- 发现目标人物时输出"WARNING"并启动蜂鸣器报警
- 按键解除报警功能

### 4. 云台控制

- 舵机云台控制（C语言实现）
- 自动跟踪目标人物

## 硬件要求

- **主控**: M0G3507
- **摄像头**: MaixPy兼容摄像头
- **云台**: 舵机云台
- **蜂鸣器**: 报警提示
- **按键**: 报警解除
